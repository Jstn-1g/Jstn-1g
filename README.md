## Featured work

### [What in the Tax?](https://github.com/Jstn-1g/what-in-the-tax)

An open-source, evidence-first property-tax explorer built from hash-locked official Ontario filings.

- Covers Ontario's current 444-municipality list; 436 municipalities have a usable 2023–2025 FIR record.
- Maintains a North Dumfries evidence model with 94 cited facts and zero current citation-audit hard failures.
- Pins 5,473 official SGC 2021 geography IDs across all 13 provinces and territories for the national ingestion foundation; jurisdiction adapters remain in progress.
- Built with Python, TypeScript, React, and GitHub Actions.
- Status: the public explorer is live; six hand-built municipal receipts remain draft previews, not sealed publications.
